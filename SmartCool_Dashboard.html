Web Serial Connection Guide
To connect this dashboard directly to your Arduino Uno:
  • Use Google Chrome, Microsoft Edge, or Opera (desktop versions support Web Serial).
  • Make sure the Arduino IDE Serial Monitor is CLOSED before clicking Connect, as only one application can access the COM port at a time.
  • Ensure the Arduino Uno is plugged in via USB and running SmartCool_Arduino.ino.
